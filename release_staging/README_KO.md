- 확인이 끝나면 이 폴더(와 이 브랜치)는 지워도 됩니다. 국면, 입력, 검증 기록, 해시, 주소는 연구 브랜치의 `basic_root/alt_first_moves/results/<실험 이름>/archive/`에 있습니다.
