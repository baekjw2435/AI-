# 대응 전략(짝 전략) 증명: 시제품 (2026-11-07)

**아스트라 제안:** 큰 국면에서 통하는 짝 전략. 상대가 어떤 단어를 고르든 아직 안 쓴 짝 단어로 받아서, 상대를 정해 둔 음절 집합 S로 돌려보냅니다.

**이 증명은 기존 v4 증명과 다른 방식입니다.**
- v4 증명서는 게임 나무(수순)를 한 수씩 적고, 검증기가 그대로 다시 둡니다.
- 대응 증명서(`pairing-proof-v1`)는 나무를 적지 않습니다. 이기는 쪽의 전략(S와 단어쌍)만 적고, 검증기는 그 전략이 모든 경우에 통하는 조건을 확인합니다.

## 무엇을 증명하나

**주장:** 이 국면에서 지금 둘 차례인 사람(A)이 집니다.

**증명서에 적는 것**
- 음절 집합 S. 지금 A가 받은 음절이 S에 들어 있어야 합니다.
- 서로 겹치지 않는 단어쌍 목록

**조건** (검증기 `verify_pairing.py`가 확인하는 것)
1. 단어쌍의 단어는 모두 아직 안 쓴 사전 단어이고, 한 단어는 한 쌍에만 들어갑니다.
2. 같은 묶음의 단어는 남은 개수까지만 씁니다. 공유 단어도 재고를 두 번 배정하지 않습니다.
3. S의 음절 뒤에 낼 수 있는 남은 단어는 모두 어떤 쌍에 들어 있습니다.
4. 쌍 {a, b}에서, S 뒤에 낼 수 있는 쪽 단어 x마다 다음이 성립합니다.
   - 다른 쪽 단어 y는 x 바로 뒤에 낼 수 있습니다(두음법칙 포함).
   - y의 끝 음절은 다시 S로 돌아옵니다.
   - 쌍의 양쪽 모두 S 뒤에 낼 수 있으면 두 방향 모두 확인합니다.

**왜 A가 지는가**
- A는 늘 S의 음절을 받은 채로 둡니다.
- A가 낼 수 있는 단어 x는 조건 3에 따라 어떤 쌍에 들어 있고, 그 짝 y는 아직 남아 있습니다.
- B는 y로 받습니다. 조건 4에 따라 합법이고, A는 다시 S로 돌아옵니다.
- 쌍은 서로 겹치지 않고 한꺼번에 두 단어씩 없어지므로, 다음 차례에도 같은 상황이 됩니다.
- 단어는 유한하므로, 결국 A가 먼저 낼 단어가 없어집니다.

**두 가지 확인 방식**
- `raw`: 실제로 남은 단어 전부에 대해 확인합니다. 게임 규칙만으로 성립합니다.
- `canonical`: 현재 단순화(verify_v3의 정규형)를 거친 국면에 대해 확인합니다.
  - 정규형 국면과 실제 국면의 승패가 같다는 사실에 기댑니다. v3/v4 증명도 같은 사실에 기댑니다.

**주의:** 증명서를 못 찾았다고 A가 이긴다는 뜻은 아닙니다. 그 국면은 이 방법으로 정해지지 않았을 뿐입니다. 아무 판정도 하지 않습니다.

## 도구

| 파일 | 하는 일 |
|---|---|
| `find_pairing.py` | CP-SAT(OR-Tools)으로 S와 단어쌍을 **찾기만** 합니다. 결과는 검증 전까지 증명이 아닙니다. |
| `verify_pairing.py` | 증명서를 따로 확인하는 작은 검증기입니다. verify_v3에서 규칙·사전·국면 해석·정규형만 가져오고, 계산기나 탐색기 코드는 쓰지 않습니다. |
| `test_pairing.py` | 작은 무작위 사전에서 완전탐색과 대조합니다. |
| `test_finder_complete.py` | 아주 작은 사전에서 모든 S와 단어쌍을 다 시도해, 탐색기의 '찾음/없음'이 맞는지 확인합니다. |
| `apply_pairing.py` | 실제 탐색에서 뽑은 국면에 제한된 시간으로 적용해 봅니다. |

```sh
python3 find_pairing.py --dictionary ../words_3436.txt --expected-word-count 3436 --position POS.json --mode canonical --seconds 60 --out CERT.json
python3 verify_pairing.py --dictionary ../words_3436.txt --expected-word-count 3436 --position POS.json --certificate CERT.json
python3 test_pairing.py 150 1        # 사전 150개, 씨앗 1
```

OR-Tools가 필요합니다: `pip install ortools`(측정은 9.15).
