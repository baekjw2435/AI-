보호막 1에서 ~놈을 제시
  상대는 보호막 0에서 놈을 받습니다.
  판정: 제시한 쪽 패  (루트 밖 순환 음절: 단어를 하나씩 두어 본 탐색)
  패배 요인(상대의 이기는 응수) 1가지:
    - 놈놈놈 → 내가 보호막 0에서 놈을 받고 짐  [보호막 0 판정(전체 사전)]
  상대가 내도 지는 응수 5가지:
    - 놈들이온다 → 내가 다갈솥으로 이김  [보호막 0 판정(전체 사전)]
    - 놈의마음속으로 → 내가 로가리듬으로 이김  [보호막 0 판정(전체 사전)]
    - 놈놀이 → 내가 이것으로 이김  [보호막 0 판정(전체 사전)]
    - 놈일 → 내가 일가친척으로 이김  [보호막 0 판정(전체 사전)]
    - 놈자 → 내가 자가보험으로 이김  [보호막 0 판정(전체 사전)]
