# 격증 필승 수순 (817단어 루트)

격을 받은 쪽이 격증으로 이기는 전략을 담은 정적 웹 모듈입니다. 상대가 어떤 응수를 하든 이기는 응수를 알려 줍니다. 서버나 데이터베이스는 필요 없습니다.

## 전제

- 사전은 기초사전 루트 817단어(격언 포함)이고, sha256은 `aa37031019f1e2a95b422ffc2f8d8d1b76b03ca88163b03b17af16ff90c79273`입니다.
- 표준두음법칙을 적용하고, 한 경기에서 단어를 다시 쓰지 않으며, 낼 단어가 없으면 집니다.
- 격을 받는 순간 817단어가 모두 남아 있어야 합니다. 상대가 루트 안의 단어(습격, 충격 등)로 격을 넘겼다면 다른 국면이므로 이 표를 쓰면 안 됩니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 단독 실행 페이지. 수순 따라가기와 상대 세 번째 응수까지의 수순표가 있습니다 |
| `engine.js` | `RouteEngine`. 정준화, 정적 역산, 되받기, 계산 없이 지는 자리로 보내는 수 찾기, 표 조회 |
| `model.json` | 음절·묶음·단어(verify_v2.py와 같은 번호), 시작 음절 `격`, 첫 수 `격증`, 표 조각 목록 |
| `shard_<묶음>.bin` | 상대 첫 응수별 승리수 표 8개, 합계 2,216,370개. 형식은 역습 표와 같습니다 |
| `test_engine.js` | Node로 돌리는 무작위 대국 시험 |

표 조각과 상대 첫 응수의 대응은 다음과 같습니다.

| 조각 | 상대 첫 응수 | 승리수 개수 | 크기 |
|---|---|---:|---:|
| `shard_438.bin` | 증후군 | 71,477 | 0.7MB |
| `shard_439.bin` | 증권 | 42,774 | 0.4MB |
| `shard_442.bin` | 증언 | 796,337 | 8.0MB |
| `shard_443.bin` | 증가율 | 39,235 | 0.4MB |
| `shard_444.bin` | 증진·증명사진 | 74,737 | 0.7MB |

증명, 증식, 증축은 짝으로 되받는 수라서 표가 필요 없습니다. 페이지는 상대의 첫 응수가 정해지면 그 조각 하나만 불러옵니다.

## 근거

- 승리수 표는 `R_gyeok_W_via_gyeokjeung.jsonl.gz`(5,673,929노드, sha256 `259b972335b9a9ae…`)에서 뽑았습니다.
- 이 증명은 수정하지 않은 verify_v2.py로 2,818초 동안 검증했습니다.
- 다음 이기는 수는 표에 넣지 않고 엔진이 직접 찾습니다. 그 결과 표가 약 17% 작아졌습니다.
  - 상대를 정적으로 지는 자리로 보내는 수
  - 정적 역산 자리의 수
  - 짝 되받기
- `engine.js`의 정준화 결과는 verify_v2.py와 353개 국면에서 일치했습니다.
- 무작위 상대 12,800판에서 실패가 0번이었습니다. 각 판은 실제 페이지처럼 첫 응수의 조각 하나만 불러와서 진행했습니다.

## 사이트에 붙이기

1. 폴더를 `dist/gyeokjeung/`으로 복사하면 `/gyeokjeung/` 주소로 열립니다.
2. 기존 화면에 넣으려면 아래처럼 씁니다.
   ```js
   RouteEngine.init(model);                       // model.json
   const key = RouteEngine.shardFor(history);     // 상대 첫 응수에 맞는 조각 번호
   RouteEngine.addTable(await (await fetch(model.shards[key].file)).arrayBuffer());
   RouteEngine.ourMove(['격증', '증언']);         // { word: '언약', how: '증명', alts: [] }
   ```
   history는 격에서 시작한 실제 단어 순서입니다.
3. 사이트의 `game-data.json`과는 번호 체계가 다릅니다. 둘을 섞지 말고 단어 문자열로만 주고받으세요.

표 조각(`shard_*.bin`, 합계 약 22MB)은 저장소에 넣지 않았습니다. 전달한 zip에 들어 있고, 증명 파일이 있으면 `build_tables.py`로 다시 만들 수 있습니다.
