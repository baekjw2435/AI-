## 칭 (추가 확정): 받는 쪽 패배

칭으로 시작하는 단어는 칭찬과 칭칭 두 개뿐입니다. 둘 다 낸 쪽이 이깁니다. 두 증명을 합친 루트 증명(296,765노드, proof_sha256 `be4b4e4e270f7782…`)이 수정하지 않은 verify_v2를 통과했습니다(142초, 받는 쪽 패배).

| 수순 | 결과 (증명에서 읽은 수) |
|---|---|
| 칭 → 칭찬 | 낸 쪽이 **찬성표**로 이김 |
| 칭 → 칭칭 | 낸 쪽은 칭찬(유일한 수)을 냄. 그 뒤 받는 쪽의 세 수가 모두 짐 |
| 칭 → 칭칭 → 칭찬 → 찬탄 | 낸 쪽이 탄력으로 이김 |
| 칭 → 칭칭 → 칭찬 → 찬합 | 낸 쪽이 합주곡(합창곡도 같음)으로 이김 |
| 칭 → 칭칭 → 칭찬 → 찬성표 | 낸 쪽이 **표현력** → 받는 쪽 역습이면 **습관적**으로 이김 |

삼룡 님이 디스코드에 올린 설명('칭칭은 적자생존을 못 쓰는 걸 이용해서 칭찬 찬성표 표현력 역습 습관적으로 이김', '칭찬은 그냥 찬성표로 이김')과 증명의 수가 같습니다. 습관적 뒤 받는 쪽이 적에서 낼 수 있는 수는 적갈색(적색·적회색도 같음) 하나만 남습니다. 칭칭이 이미 쓰여서, 적자생존 → 존칭으로 칭에 돌아오면 칭에서 낼 단어가 없기 때문입니다.

817단어 중 칭으로 끝나는 단어(극존칭, 명칭, 삼인칭, 존칭)와 존으로 끝나는 단어(병존, 적자생존)를 모두 계산했습니다. 칭칭은 칭에서 칭으로 가는 단어라 칭을 '넘기는' 단어가 아닙니다.

존칭만 다른 이유: 존으로 시작하는 단어는 존칭 하나뿐이라, 존칭이 쓰이면 존에서 낼 단어가 없습니다. 그러면 '적자생존 → 존칭 → 칭칭' 끝내기가 사라지고, 거꾸로 적자생존(존을 넘기는 단어)이 받은 쪽의 무기가 됩니다.
