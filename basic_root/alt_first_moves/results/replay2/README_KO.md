# 전략 재생 실험 2 (2026-11-12): 비교용 12개로 확인

## 결론

- **검증까지 넣은 시간 합계는 직접 4,752초, 재생 1,513초입니다(3.1배).** 직접 탐색이 못 푼 2개는 한도까지 쓴 시간(약 601초)으로 셌습니다.
- **재생이 늘 빠르지는 않습니다.** 12개 중 2개는 재생이 더 느렸습니다(언어능력 0.3배, 풍력 0.8배). 법률은 거의 같았습니다(1.1배).
- **원본 증명은 새로 준비하지 않았습니다.** 실험 1에서 만든 역·승·율·행의 증명서를 다시 썼습니다.

  - 비교용 음절, 검증된 판정 없음, 넘겨주는 음절의 원본 증명서가 준비됨(32개).
  - `sha256("alt817-replay-final-v1:" + id)` 순서로 앞의 12개(`../../replay_pick.py`).

- '전체' 시간 = 계산기 프로세스의 실제 시간 + 검증기 실행 시간.
