# 기존 자료 재사용 시험: 습 원본 (2026-11-15)

예전 연구의 '습 받음, 단어 없음' 증명 파일(verify_v2, 5,248,098국면)은 남아 있지 않고, 그 증명에서 뽑은 승리수 표(기존 지도의 책 `kc2b5`, 1,970,056항목)만 있습니다. 이 표를 **수 선택 힌트**로 써서 새 v4 원본 증명서를 만들고, 바꾸지 않은 `verify_v4`로 검증했습니다.

## 결과

- **완성, 검증 통과.** 습을 받은 쪽 승(이기는 첫 수 습식). 예전 연구의 판정과 같습니다.
- 수락 조건(`solve_common.verify`)을 모두 통과: 종료 코드 0, verified true, 판정, 상태 저장 방식, 사전·국면·입력·증명서 sha256.

## 어떻게 했나

- 실험용 계산기 `solver_v5_table`(`guopsaem_root/solver_v5/experiments/table/`): 재생 계산기의 사본에 '표 안내'를 더했습니다.
  - 이기는 쪽 차례(예상 W)면 표의 수를 먼저 둡니다. 표의 열쇠는 기존 지도 엔진과 같게 계산합니다(사이트 정준형, 핵심 크기로 파일 선택, 앞 `width`비트).
  - 지는 쪽 차례(예상 L)면 실제 남은 단어로 모든 합법적인 수를 확인합니다.
  - 값은 모두 실제 국면에서 계산기 자신의 코드로 정합니다. 표는 어떤 수를 먼저 둘지만 정합니다. 표가 맞지 않으면 기존 재생처럼 막힌 곳마다 짧게 탐색합니다(이번에는 0번).
  - 증명서는 바꾸지 않은 쓰기 코드로 쓰고(`--emit-check 0`, 재생과 같음), 바꾸지 않은 검증기가 받아들여야 확정입니다.
