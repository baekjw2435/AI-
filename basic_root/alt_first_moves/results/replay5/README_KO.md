## 보관

- 증명서 파일 52개(96MB)는 저장소에 넣지 않습니다. GitHub 릴리스 `alt817-proofs-replay5`의 첨부파일로 둡니다.
- 상태: staged: the files are not attached to the release yet
- 저장소에는 국면(`archive/<사례>/pos.json`), 입력(`in.txt`), 보관본을 다시 검증한 기록(`verify.json`), 그리고 파일마다 sha256과 주소를 적은 색인(`archive/INDEX.json`)이 있습니다.
- 올린 뒤 확인: `python3 replay_archive.py replay5 --check-release 1` (주소마다 다시 내려받아 sha256 비교).

- 대상은 실행 전에 `cases.json`으로 고정해 먼저 커밋했습니다.
