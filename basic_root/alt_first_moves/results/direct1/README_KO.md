# 직접 탐색 묶음: direct1

재생이 600초 안에 못 푼 첫 수 10개 중, 직접 탐색을 아직 안 해 본 9개를 기본 계산기로 600초씩 직접 탐색했습니다(2026-11-13). 순발력은 묶음 1의 직접 탐색 600초 기록을 그대로 쓰고 다시 돌리지 않았습니다. 중간에 작업 환경이 두 번 재시작돼, 격돌·역기능·돌솥은 저장 상태에서 남은 시간만 이어 돌렸습니다.

## 결과

- 첫 수 9개 중 **1개 확정**(지는 수 0, 이기는 수 1), 미확정 8개.
- 확정은 모두 그 국면의 v4 증명서가 C++ `verify_v4`의 수락 조건을 통과한 것입니다.
- 걸린 시간 합계(계산기 + 검증): 5,302초. 탐색 5,230초, 증명서 쓰기 31초, 검증 37초.
- 재시작으로 끊긴 실행 3개, 증명서를 못 썼거나 거부된 실행 0개.
- 재시작으로 끊긴 실행(격돌, 역기능, 돌솥)은 저장해 둔 상태에서 남은 시간만 이어 돌렸습니다. 마지막 저장 뒤 끊길 때까지 한 탐색(저장 간격 60초 이하)은 잃었고, 위 합계에 들어 있지 않습니다.

## 보관

- 증명서 파일 1개(12MB)는 저장소에 넣지 않습니다. GitHub 릴리스 `alt817-proofs-direct1`의 첨부파일로 둡니다.
- 상태: 아직 릴리스에 올리지 않았습니다. 파일은 세션 브랜치의 `release_staging/`에 있습니다.
- 저장소에는 국면(`archive/<사례>/pos.json`), 입력(`in.txt`), 보관본을 다시 검증한 기록(`verify.json`), 그리고 파일마다 sha256과 주소를 적은 색인(`archive/INDEX.json`)이 있습니다.
- 다시 확인하려면: `python3 replay_archive.py direct1 --check-release 1` (주소마다 다시 내려받아 sha256 비교).
