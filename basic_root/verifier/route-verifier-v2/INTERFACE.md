New engine interface v1 (2026-10-28)

Dictionary words are distinct tokens. Standard dueum maps final syllables: ㄹ before ㅑㅕㅖㅛㅠㅣ -> ㅇ, other ㄹ -> ㄴ; ㄴ before ㅕㅛㅠㅣ -> ㅇ. All words in this dictionary have unchanged first syllables. Canonical syllable list is sorted Python Unicode order of starts and normalized ends. Groups are sorted (source_id,target_id); counts = number of distinct words in group. Exact history is validated word by word and decrements corresponding groups BEFORE normalization.

Numeric solver input UTF8: first line N G CURRENT; next G lines SOURCE TARGET REMAINING_COUNT. Group order is fixed by model.json prepared by parent. Values <=255. Solver CLI to be established by its author. Exact state uses CURRENT plus all G count bytes; collision hashes must compare full keys. Safe canonicalization: for u!=v remove min(c[u,v],c[v,u]) from both; for self loops c%=2; then drop edges whose source is unreachable from CURRENT through positive remaining edges. Pair removal preserves outcome via strategy-transfer; certificate describes reduced strategy; physical full strategy can answer opponent's removed edge with reserved reverse. No other reductions without review.

Proof JSONL: header {"format":"route-proof-v1","groups":G,"vertices":N,"root":ROOT_ID,"input_sha256":OPTIONAL}; each subsequent line is a node {"id":ID,"v":CURRENT,"c":COUNTS_HEX,"r":"W" or "L","m":[[GROUP_ID,CHILD_ID],...]}. IDs contiguous from0, children strictly earlier; root last. Root counts/current must equal independent normalization of separately supplied exact-history manifest. Counts hex is all G counts, two hex chars per count. W node exactly1 move to L child; L node includes EVERY legal reduced group once, each to W child. Terminal L has empty m. Every move decrements one group, switches current to its target, then canonicalizes as above. Unknown states must NEVER appear in proof or be cached as solved. Solver may store/search unknown but no winning/losing promotion on budget.

Verifier must independently reconstruct model/numbering FROM ORIGINAL DICTIONARY, validate history and compare numeric input, implement own Korean normalization/count reduction/graph traversal, and verify each proof node and transition. No importing solver's model builder. It should use original words to check history reuse. Tests should include proof mutation rejection, different-history/root mismatch rejection, and tiny raw exact word-level games vs normalized solver.

Only new cache namespace. Legacy FCT1 files are never read as truth or imported speculatively.
