새로 만든 끝말잇기 독립 검증기 v2
2026-10-28

1. 이 파일 묶음은 무엇인가요?

Python 독립 검증기 원본과 필요한 파일입니다.
verify_v2.py가 v2 검증기이고, 같은 폴더의 verify.py도 필요합니다.
Python 3.10 이상을 권장합니다. Python 검증에는 추가 패키지가 필요 없습니다.

검증기는 탐색기가 만든 증명 자료를 검사합니다.
사용 이력만 입력해 새 승패를 찾는 작업은 탐색기의 역할입니다.
보조 자료로 새 C++ 탐색기 소스 solver_v2.cpp도 함께 넣었습니다.

2. 가장 간단한 실행

압축을 풀고 이 폴더에서 다음을 실행하세요.

python check_example.py

verified: true가 출력되면 동봉한 예제 증명이 통과한 것입니다.
예제는 실제 817단어 목록에서 푼돈 → 돈푼 뒤 푼을 받는 자리입니다.
이때 푼돈을 이미 사용했으므로 낼 단어가 없어 현재 차례가 패배합니다.
이 예제는 설치 확인용이며 역풍 또는 식 자리의 증명이 아닙니다.

3. 다른 증명 검사

python verify_v2.py --dictionary words.txt --position position.json --input input.txt --proof proof.jsonl

position.json의 최소 형식:
{"initial_syllable":"역","history":["역습","습격","격식"]}

history에는 시작부터 실제로 사용한 단어를 순서대로 모두 적습니다.
initial_used_words를 지정하면 시작 전 사용한 단어도 제외합니다.
같은 단어를 양쪽에서 다시 쓰는 것은 허용하지 않습니다.

proof.jsonl은 새 route-proof-v2 형식이어야 하며 gzip 파일도 읽습니다.
input.txt는 단어 목록과 이력에서 만든 탐색기용 숫자 입력입니다.
--input은 보통 함께 지정하세요. 증명 헤더가 input_sha256을 선언하면 필수입니다.
검사에 성공하면 verified: true와 현재 차례의 W 또는 L을 출력합니다.
실패하면 verified: false를 출력하고 종료 코드 1을 반환합니다.

4. 검사하는 내용

원본 817단어, 표준두음 적용, 전체 사용 이력과 단어 재사용을 확인합니다.
승리 증명은 패배하는 자식 자리로 가는 수를 확인합니다.
패배 증명은 축약된 자리의 모든 합법 선택을 확인합니다.
왕복 쌍 제거와 정적 역산으로 생략된 부분은 보존 정리에 따라 독립 재계산합니다.
축약의 이유와 증명은 model_audit.md 및 INTERFACE_v2.md에 있습니다.

이 버전은 제공된 817단어 모형을 대상으로 합니다.
약 3만 단어의 전체 기초사전과 같은 승패라는 주장은 포함하지 않습니다.
기존 FCT1 .facts 캐시나 예전 프로그램의 다른 증명 형식은 직접 읽지 않습니다.
기존 캐시의 형식이 달라도 이 묶음의 검증기를 사용하는 데 지장은 없습니다.
다만 기존 캐시를 새 프로그램에 옮기는 작업은 별도로 확인해야 합니다.

5. 시험 자료와 선택 사항

verification_v2_test_results.json에는 개발 환경에서 통과한 검사 기록이 있습니다.
11개 검사, 작은 판 1,488자리 대조, C++ 증명 180개 독립 검사를 포함합니다.
변조된 승패·누락된 선택·다른 이력·재사용·잘못된 자식 상태 거부도 확인했습니다.

Python 검사를 다시 실행하려면:
python -m unittest -v test_verifier_v2.py

C++ 실행 파일이 없으면 C++ 연동 검사 한 개는 건너뜁니다.
연동 검사까지 실행하려면 먼저 다음처럼 컴파일하세요.
g++ -O3 -std=c++17 solver_v2.cpp -o solver_v2
Windows에서는 실행 파일 이름을 solver_v2.exe로 정하고 환경에 맞게 실행하세요.

6. 연구 상태

examples/yeokpung와 examples/sik에는 탐색 대상의 정확한 이력만 들어 있습니다.
이 두 폴더에는 검증을 통과한 새 증명 파일을 넣지 않았습니다.
이번 새 탐색기는 이 자리들에서 상태 한도에 도달해 미확정으로 남겼습니다.
기존 탐색 기록의 판정은 별도 자료로 보존되어 있으며 이 묶음에서 재확정한 것이 아닙니다.

이 ZIP에는 원래의 대형 캐시, 새 탐색 캐시, 사이트 로그인 정보가 포함되지 않습니다.
