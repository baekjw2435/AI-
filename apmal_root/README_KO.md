# 앞말잇기 루트전·보호막전 (표준사전)

**앞말잇기**: 다음 단어는 앞 단어의 **첫 음절**로 끝나야 합니다. 예: 차도 → 기차 → 상기 → 미상.
두음은 **표준 두음법칙**(한 방향)입니다. 라디오 다음에 옳다구나 가능(라→나), 자수 다음에 여자 가능(녀자는 사전에 없음).

## 어떻게 계산하나: 단어를 모두 거꾸로 뒤집는다

단어를 모두 거꾸로 뒤집으면 앞말잇기는 끝말잇기와 규칙이 똑같아집니다
(뒤집은 단어의 끝 음절로 시작하는 뒤집은 단어를 낸다, 두음 함수도 같음).
그래서 끝말잇기에서 쓰던 계산기와 검증기를 **고치지 않고** 뒤집은 파일만 넣어 씁니다.

- 루트: `solver_v5`(계산) → `verify_v4`(검증, 수락 조건 8개). 뒤집은 루트 단어 파일 `words_534.txt`를 사전으로 넘김.
- 보호막: `eoinjeong_root/shield/` 도구를 `SHIELD_GAME=front`로 실행. 계산·검증 규칙은 끝말잇기와 같고,
  화면과 표에 낼 때만 단어를 다시 바로 뒤집습니다. 기본값(`SHIELD_GAME` 없음)은 지금까지의 끝말잇기 그대로입니다.
- 사람에게 보여 주는 표와 보고는 모두 **원래 단어**(바로 뒤집은 것)로 씁니다.

## 자료

| 파일 | 내용 |
|---|---|
| `source/` | 받은 원본 그대로(루트 단어 음절1·음절2·짝, 공격 목록) |
| `../standard_words.txt` | 표준사전 291,652단어(원래 방향) |
| `reversed/표준사전_뒤집음.txt` | 사전 단어를 모두 뒤집은 것 |
| `reversed/루트단어_뒤집음.txt` | 루트 단어(음절 줄 113, 짝 줄 104)를 뒤집은 것 |
| `reversed/공격단어_뒤집음.txt` | 공격 목록을 뒤집은 것(깊이 1 = 한방만 씀) |
| `words_534.txt` | 뒤집은 루트 단어 534개(solver_v5·verify_v4 사전) |
| `syllables_113.txt` | 루트 음절 113개 |
| `build_front.json` | 셈과 sha256 |
| `shield/syllable_shield_table.tsv`, `shield/attack_words_shield.tsv` | 앞말잇기 보호막 표(원래 단어) |
| `results/roots/` | 루트 국면별 계산 기록(res), 증명서(proof) |
| `site/data.json` | 루트 확정 결과(보호막 도구가 읽음). 113음절이 모두 확정된 뒤에 만듦 |

다시 만들기: `python3 apmal_root/tools/build_front.py` (검사가 하나라도 틀리면 멈춤).

## 규칙(사용자가 정한 것)

- 검증기를 통과한 것만 **확정**, 아니면 **미확정**.
- 질문 하나에 30분 한도. 넘으면 먼저 묻는다.
- 계산기는 동시에 4개까지만.
- 그 음절로 이을 단어 수가 보호막보다 적으면 승패가 아니라 **제시할 수 없음**.
- 끝말잇기 결과(eoinjeong_root의 확정 결과, basic_root/, guopsaem_root/)는 고치지 않는다.

## 루트 계산 한도(`results/run_config.json`)

- 1차: 국면마다 탐색 600초, 표 1GB, 4개 동시.
- 2차: 1차에서 미확정인 국면만, 저장한 탐색 상태에서 이어 1200초 더(합계 30분), 표 2GB, 4개 동시.
- 그래도 미확정이면 미확정으로 두고 사용자에게 묻는다.
