# ─────────────────────────────────────────────────────────────
#  복합 봇 연구 규칙
#  여기에 적은 것만 봇이 씁니다. # 뒤는 설명이라 봇이 읽지 않습니다.
#
#  쓸 수 있는 줄은 세 가지입니다.
#
#   금지: 글자 보호막들      → 그 보호막에서 그 글자로 끝나는 수를 두지 않습니다.
#                             (= 그 자리에서 그 글자를 제시하면 지는 경우)
#   노림: 글자들 보호막      → 그 보호막에서 그 글자를 넘기면 좋은 경우입니다.
#   연구수: 글자 보호막 = 단어들
#                           → 그 글자를 그 보호막에서 받았을 때 둘 수입니다.
#                             쉼표나 / 로 여러 개를 적으면 앞에 쓴 것부터 씁니다.
#
#  금지가 최우선이고, 그다음이 한방, 그다음이 연구수입니다.
#  금지 때문에 둘 수가 하나도 없으면 그때만 금지를 풉니다.
# ─────────────────────────────────────────────────────────────

# ── 틀로 유인하기 ─────────────────────────────────────────────
# 공격 단어가 '~틀' 하나뿐인 글자입니다.
# 보호막 5에 넘기면 상대는 공격하려다 보호막 4에서 틀을 제시하게 됩니다.
# 삭은 뺐습니다. 3강 6번 줄에서, 삭을 5에 넘기면 받은 쪽이
# 삭삭·삭즉삭 돌림 2개로 보호막을 2까지 내리고 삭임틀2 를 써서 이깁니다.
노림: 뀀,녓,뜀,띰,렷,엿 5


# ── 션 (2강) ──────────────────────────────────────────────────
# 션보롬에서 갈립니다. 롬 자리에 이 셋이 있습니다.
#   롬곡옾눞  끝 '눞' 후속 0   → 보호막 0 에서만, 즉사
#   놈삐썹    끝 '썹' 후속 2   → 보호막 2 이하에서만
#   놈놈 · 놈놈놈                 돌림 2개
# ~션을 보호막 H 에서 전개하면 상대가 션보롬으로 받고, 내가 롬(H-2)에 섭니다.
#   H=0,1,2 → 롬0 즉사 / H=3 → 롬1 / H=4 → 롬2 / H=6 → 롬4
#   H=5 → 롬3 패 / H=7 → 롬5 패 / H=8 → 롬6 패
금지: 션 5,7,8
노림: 션 0,1,2,3,4,6

# 롬 자리에서 두는 수입니다.
연구수: 롬 0 = 롬곡옾눞
연구수: 롬 1 = 놈삐썹
연구수: 롬 2 = 놈삐썹
연구수: 롬 4 = 놈놈
# 돌림을 한 번 쓰면 그 뒤로는 '놈' 자리라 롬곡옾눞을 못 씁니다.
연구수: 놈 1 = 놈삐썹
연구수: 놈 2 = 놈삐썹

# 롬을 넘기는 쪽에서 본 규칙입니다.
# 받은 사람이 0,1,2,4 에서 이기므로 그 앞 보호막에서는 넘기지 않습니다.
금지: 롬 1,2,3,5
노림: 롬 4,6,7
